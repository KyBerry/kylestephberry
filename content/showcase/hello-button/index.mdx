A trivial component used to exercise the showcase pipeline end-to-end. Click
the button; the counter under it goes up. The point isn't the interaction —
it's the surrounding scaffolding: schema validation, transform extracting the
source text, Shiki highlighting at build time, and Next bundling the component
itself so it can render live inside the frame.
